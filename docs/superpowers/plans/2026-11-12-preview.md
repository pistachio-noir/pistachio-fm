# Space preview implementation plan

**Goal:** Preview one selected file without opening another application.

**Design:** Reuse the existing QML popup styling, with a large content area, filename,
location, and Close button. Space opens from the focused file view; Space/Escape close.
Text fields retain normal spaces. Scope defaults to text and Qt-readable images, pending
the owner's optional format preference. Unsupported formats show an explicit message.

**Approaches:** A Qt-only dialog uses existing dependencies and matches the application.
An external preview application depends on desktop services and has different styling.
Qt PDF/multimedia modules would add dependencies absent from the current installation.
Use the Qt-only dialog for the common core authorized by the implementation request.

**Architecture:** A per-dialog C++ Preview object loads a bounded text prefix in the
worker pool and discards stale results after closing/reopening. QML renders text as
plain, read-only content and loads image URLs asynchronously at bounded dimensions.
No file writes, execution, markup rendering, or changes to default applications.

**Constraints:** Qt 6.9+, no new dependencies, colours only from Theme.qml, existing
dialog focus/close conventions. Keep all earlier search work intact; no commits.

**Review focus:** binary/special files, Unicode and truncation, errors, obsolete worker
results, URL-sensitive filenames, focus in text fields, no selection/multiple selection.
