# Pistachio Noir file manager (design boards)

- html/ : standalone pages, open directly in a browser (1040x640 boards)
    browse-grid.html, list-context-menu.html, trash-dialog.html
- canvas-source/ : original design canvas files (.dc.html + canvas.json)

Sample file names, sizes and dates are made up.
Colours: Pistachio Noir tokens (#0D0F09 #15170F #1D2016 #2A2F1F #39412A #A3B08F #E5E9D8 #F6F8EF #9FD88A #DB8267 ...). Fonts: Manrope, JetBrains Mono (Google Fonts).
